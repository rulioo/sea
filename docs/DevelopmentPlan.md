# 《海商：世界商路》开发计划(给决策者看的全景)

> 项目代号 **SEA** | 引擎 Unity 6000.0.30f1 | 目标:复刻《大航海时代4》的**玩法内核**,画面与内容全部原创。
> 本文档讲三件事:**我们做的是一款什么游戏 → 现在做到哪了 → 分几步、每步你能看到什么**。
> 配套的《GameDesign.md》是"玩法与数值设计参考";本文档是"接下来怎么走"的执行计划,以真实代码进度为准。

---

## 1. 我们在做一款什么游戏

> **一句话:** 你在 16 世纪(1550 年)的真实世界地理上开商船做生意 —— 在物产便宜的港口买进,
> 运到当地百姓急需的港口高价卖出;靠差价赚钱、换大船、招能人,把商路越铺越远,成为海上第一商人。

它为什么"神似大航海4"?因为核心玩法同构:

- **一张真实世界地图**,港口有各自的物产和百姓需求;
- **低买高卖 + 会看行情**:价格随季节、随机漂移、大事件(战争/饥荒/节日)变动;
- **开船要盘算**:距离 = 天数,船上要带食粮/淡水/防坏血病的茶与维生素,水手多就吃得多;
- **越玩越强**:雇水手、买更快的船、招有本事的副官;交易有信誉,能解锁更多海域;
- **一个看得见的大目标**(第 4 节)。

**护栏(我们明确不做):** 不复制原版的任何人物/剧情/立绘/数值;不做写实 3D 开放世界(自由开船到处逛);
不做联网多人;不堆"复杂到累"的数值 —— 先把"好玩、能看懂"做到位。

## 2. 现在做到哪了(诚实版)

### 2.1 地基 —— 已完成,看不见但最值钱

| 内容 | 规模 |
|---|---|
| 真实史地世界:8 大航区 + 世界地图陆地几何 | ✅ 8 航区 / 全球海岸陆地数据已生成并验证 |
| 港口 + 商品 | ✅ 52 座真实地理港 / 39 种历史物产 |
| 大事件 | ✅ 14 条(1550 年起按日期触发,扰动行情) |
| 经济规则引擎(纯代码,可离线仿真) | ✅ 供需 + 季节 + 行情漂移 + 交易反馈 |
| 舰队规则:货舱 / 补给 / 工资 / 士气 / 坏血病 / 海盗(自动) | ✅ |
| 舰船 / NPC 船员数据 | ✅ 15 型船 / 10 位名人(带技能与招募门槛) |
| 自动化回归闸门(SimCheck) | ✅ 全部断言绿 |

> 这套东西的价值:数值和内容可以被脚本反复压测、不会越改越坏;将来想"换皮肤/换世界"只改数据。

### 2.2 能玩的最小一圈 —— 已完成(骨架)

> **塞维利亚装货 → 选目的地 → 海上过日(吃口粮、防海盗) → 到港结工资/治伤 → 卖货拿钱 → 再进货再走。**

这个循环已经真实能跑,并且已打成**可双击的独立 exe**(`Build\SEA.exe`,不用开 Unity 编辑器)。

### 2.3 还没有的"壳" —— 这是接下来全部重点

| 缺什么 | 现在的样子 | 目标 |
|---|---|---|
| 游戏画面(定妆) | 占位:方块大陆 + 圆点港口 + 能自由转的镜头 | 固定俯视的海图风世界 + 立体船在海上开(第 5 节 A 阶段) |
| 界面排版 | 能用但很素的代码面板 | 港口行情 / 出航 / 补给等排版得像原作那样"一眼会用" |
| 目标与成长线 | 还没有 | 让你随时知道"我为什么在跑"(第 4 节) |

> **请记住:** 你现在看到的所有"难看",都不是最终样子,是美术/呈现还没做的占位层。

## 3. 目标游戏的画面(定妆愿景,按你定的方向)

你已拍板的关键选择:**航海画面 = 保留 3D 船模 + 视角锁定俯视/海图化**(不做自由绕视)。

展开的图景:

- 打开游戏 = 一张能一眼看懂的世界海图:陆地按航区着色、有海岸线,海是统一的底色;整体像一张"活的地图",而不是让你迷失的 3D 海域。
- 你的船是一条**看得见起伏、破浪前进的 3D 船**,沿着你点的航线在图上走。
- 港口 = 带名字的小标记,点它 → 弹出该港行情 → 买卖、补给、出航。
- HUD:现金/日期/船况/给养常驻;交易、日志清楚可读。
- 放大缩小有层级:拉近看港区,拉远看全航线。

## 4. 大目标:让你"知道自己在玩什么"(待你拍板)

下面是一条**原创建议线**(不照搬原版剧情),请你读完确认或改动,定了我们就照它做目标系统:

> **1550 年,你只是塞维利亚一条小船上的穷船长。**
> 目标:把商路从地中海 → 西非 → 好望角 → 印度洋 → 东南亚 → 东亚一路打通,**点亮一张世界商路图**;
> 每到一个新航区就争取"贸易特权/独占某样名产";攒钱换更大的船、招有名的船长当副官;
> 用**交易声望**冲击每年商会年度的"商誉榜",最后成为公认的海上商界第一人。

备选味道(可混搭):① **冒险探宝线**(按传闻出海找传说中的航线与宝藏);② **商会争霸线**(和几大商会抢航线、抢名产)。
主线不必只一条,但**第一版只做一条,让你能从头到尾走通**,再加别的。

## 5. 开发路线图(分阶段,每步都给你能跑的 exe)

> 原则:每完成一个阶段,我都打成新的 `Build\SEA.exe` 给你双击试玩;
> 你只按「**现象 → 期望**」反馈,我再往下走。不做看不到东西的长周期。

### A. 定妆画面 —— 把世界做成"游戏地图"(✅ 第一版已交付 `Build\SEA.exe`)
- 做什么:按第 3 节愿景重做世界呈现:固定俯视海图化;立体船破浪;港口标名;镜头锁定与缩放层级。
- 你会看到:不再是一堆方块,而是一眼能认出的世界地图 + 你的船。
- 本版改动(2026-09-05):镜头锁定为**高空固定俯视(北在上、东在右)**,右键绕视已移除,只留滚轮缩放 + 中键平移;出航自动拉近到能同时看到两个港,到港落近港区;陆地压成低平顶、海面放平静,俯视下像一张活地图。
- 待你试玩反馈:方位是否对、总览远近是否合适(这两点无头看不出来)。
- 验收:你双击 exe,觉得"这开始像款游戏了"。

### B. 操作与界面 —— 让游戏"一上手会用"(✅ 两版已交付 `Build\SEA.exe`)
- 做什么:出航 / 进港 / 行情表 / 补给 / 招募 / 日志的排版与交互;颜色标价;按钮反馈;教程提示。
- 你会看到:像原作那样清楚的行商面板,不用我教就知道点哪。
- 验收:你不看文档也能完成"买→跑→卖→赚"一整圈。
- 本版改动(2026-09-05 · v1):开局镜头直接对准塞维利亚(球标大、可点);顶部"试炼目标=净赚 15 万"进度条常驻;左下"本港行情"到港自动弹开(◆特产/▲抢手,便宜绿、贵红,+买10/卖);底部操作条每一步都用一句话告诉你"现在该点哪"(点发光球选港 → 金色『出航』);航行中显示"驶向×× 第×/×日"进度;现金/日期/货舱/水手/士气/续航常驻左上。
- 本版改动(2026-09-05 · v1.1):右上常驻「⚙ 设置」齿轮 → 保存进度 / 载入进度 / 音乐音效 / 退出游戏。音乐音效子页:点选 BGM 曲、音乐与音效两条**拖动滑杆**、全部静音开关。点击按钮、买卖成功、保存、退出均有音效。存档为**单档**(sea_save.json,存"当前港+全舰队+全港行情快照"),**航行中不可存**(提示先靠港);载入后回到存档当天的港与行情。BGM 在 `Assets/Resources/bgm/`、音效在 `Assets/Resources/sound/`(放文件即生效,重启游戏加载)。
- 待你试玩反馈:布局/字号/引导是否顺、开场是否一眼知道点哪;滑杆手感、静音开关、存档后是否想存时就能存(无头无法替代肉眼)。

### C. 目标与成长 —— 让游戏"有奔头"
- 做什么:第 4 节的目标线落地:交易声望、点亮新航区、买船换船、招募名人副官、商誉榜。
- 你会看到:一个明确的目标 + 进度反馈,"我为什么在跑"一直有答案。
- 验收:你能从零跑出一整条目标线。

### D. 风险与深度(可选手操)
- 做什么:海盗从"自动结算"升级为可选的**手操海战**(原版大航海4 有掌舵炮击),大事件/传闻真正影响你决策。
- 验收:航海的紧张感与决策感上来。

### E. 内容扩展与润色 —— 让它"够玩、好看"
- 做什么:加港/加货/加事件/加 NPC;统一美术、音效、动效;数值平衡(用 SimCheck 压测)。
- 验收:给你朋友玩不丢人,可作为"能发布的成品"。

**标注:** 旧 `GameDesign.md` §9.3 里的 M0–M3 是项目早期的叫法,写作时经济引擎还没完成;实际上 M0/M1 及 M2 的大部分规则已做完,上面 A–E 以"你能看到什么"为准,不再沿用旧编号,避免混淆。
