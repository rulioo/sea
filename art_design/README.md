## 1. 美术风格口径 —— 半写实厚涂 · 航海油画感

- **基调**: 像 17 世纪荷兰航海油画的**光与暗**: 暗沉深蓝海面、暖赭灯光、粗帆与油皮。
- **写实锚点**: 服装/道具考据 1550 年代真实材质与地区服饰(见每页"地区锚点")。
- **造型**: 剪影清晰、五官硬朗; 允许**适度夸张**(角色化脸型/标志性配饰), 不追求照片级。
- **画法**: 厚涂块面, 笔触可见; 暗部统一偏冷青; 皮肤高光暖; 少而肯定的收线, 不描全边。
- **旧化**: 帆有补丁与盐渍、皮革有磨痕、黄铜氧化偏暗——**"用了十年"**胜过"刚出厂"。
- 尺寸: 角色立绘比例约 6.2 头身(青年) / 5.8(老年); 肤色/面部做角色化但不脸谱化。

**船·布·皮(主体)**

|---|---|---|
| 深靛 | `#20344A` | 北欧呢料/深海军装 |

| 帆麻 | `#E7D9B6` | 亚麻衬衫/帆布 |
| 鞣革 | `#7A4B2B` | 皮带/外套/靴 |
| 柚木 | `#8A5A2B` | 船木/甲板 |
| 橡褐 | `#6B4423` | 深色木/柜 |

**金属·火器**
| 名称 | Hex | 用途 |
|---|---|---|
| 黄铜 | `#C19A3B` | 星盘/罗盘/钮扣(偏哑光) |

| 铁灰 | `#3A4148` | 炮/刀剑/盔甲 |
| 铜绿 | `#4F7C6B` | 青铜腐蚀的"年代感"点缀 |

**货·香料·警示**
| 名称 | Hex | 用途 |
|---|---|---|
| 旧纸 | `#D9C08A` | 海图/账本/标签 |
| 帆白 | `#F0E8D2` | 高光/布 |
| 陶土 | `#B0522F` | 陶器/陶土瓦 |
| 猩红 | `#8E3A2F` | 徽记/危险/海盗 |
| 青柠 | `#7C8E2E` | 维生素补给 |
| 茶褐 | `#6B4A2F` | 茶叶/深色编织 |
| 墨线 | `#191C1E` | 收线/阴影最深 |

> 规则: 每页主色 ≤ 4 个 + 1 个点缀。暗部统一偏向 `深靛/墨线`, 不喧宾夺主。

## 3. 单页设定稿模板(每一稿都含这些字段)

```
【名称·代号】  分类 / 身份 / 是否原创
· 时代·地区锚点   (一句话考据依据)
· 剪影           (一句话: 一眼认得出的形状)
· 姿态·体态       (高矮/肩/气质)
· 服装逐项       上装 / 下装 / 外套 / 头饰 / 鞋 / 随身件(逐条短句)
· 主色           (直接给 2~4 个 hex)
· 材质·旧化       (布料/皮/金属各自的质感一句话)
· 设定缘由        (为什么这么穿/这么带, 接玩法或剧情)
· 出图提示词      (中文, 可直接喂 AI 生图)
· 待办           (三视图/表情/动作等画师事项, 打勾用)
```
