# 港口众生 · 美术设定稿(功能性群像)

> 每个港口都会有的"功能位角色", 非固定 NPC → 需做**地区变体**才能跑遍 8 航区。
> 每页给"主色基调 + 变体提示": 主色代表一张母版, 地区换装按页尾《地区服饰速查》改。
> 模板与色板见 `../README.md`。风格: 半写实厚涂航海油画感。

---

## 1. 酒馆老板娘 —— 情报/招募点
- 游戏里: 花金币买传闻(大事件 telegraph), 或介绍可招募水手/船员。
- 剪影: **围裙 + 高挽袖 + 腰间一串钥匙**; 圆润而精, 常在擦同一只酒杯。
- 服装: 帆麻 `#E7D9B6` 衬衣 + 深色束腰长裙(地中海式), 外罩系带围裙; 头巾卷至额上。
- 主色: 帆麻/靛蓝染 `#2E4B8F`/陶土 `#B0522F`(围裙)。
- 随身: 钥匙串、一本手写"水手信誉"簿、柜台后酒桶(柚木 `#8A5A2B`)。
- 出图提示词: 半写实厚涂, 港口小酒馆老板娘擦酒杯, 系带围裙高挽袖, 腰间钥匙串, 暖灯照酒桶, 中年亲切又精明。

## 2. 船匠(造船厂主) —— 造/改/卖船
- 游戏里: 造船、改造(refit §4)、卖旧船。
- 剪影: **皮围裙 + 肩头别木尺 + 一只眼睛贴着墨线眯起**; 虎背熊腰。
- 服装: 帆麻工装 + 柚木渍围裙, 布腰带插凿刀; 头绑旧布巾。
- 主色: 柚木 `#8A5A2B`/帆麻/铁灰 `#3A4148`(工具)。
- 随身: 木尺、图纸卷、炭笔; 背景有船台龙骨(剪影即"人在船前")。
- 出图提示词: 半写实厚涂, 造船厂主腰围插凿刀的皮围裙, 眯眼校准木尺, 背后半完工船体, 木屑与暖光。

## 3. 港务税务官 —— 行市/税收/声望
- 游戏里: 通报进出港行情、收停泊税、发放航路许可。
- 剪影: **高领大氅 + 托着一本摊开大账册**, 站姿像尊雕像, 羽毛笔别在耳后。
- 服装: 深靛 `#20344A` 长袍 + 白亚麻立领; 帽为方顶软帽(时代感"学者/吏员帽")。
- 主色: 深靛/旧纸 `#D9C08A`(账册)/墨线 `#191C1E`。
- 随身: 大账册、羽毛笔与墨水瓶、腰间印章盒(蜡印)。
- 出图提示词: 半写实厚涂, 15xx年港口税务官托摊开大账册, 深靛高领大氅白亚麻立领, 耳后别羽毛笔,
  方顶软帽, 印章盒在腰, 公事公办神情。

## 4. 传教士 —— 治疗/祈福/远港情报
- 游戏里: 治坏血病更快(阿妮塔之外的第二途径), 顺带给"下一港圣人节"传闻。
- 剪影: **深褐修士袍(束绳) + 胸前一枚木十字 + 总背一只旧皮包**; 清瘦、衣摆起毛。
- 服装: 陶土 `#B0522F`-偏深的修士袍 + 麻绳腰带; 一双草编凉鞋。
- 主色: 陶土/旧纸/帆白 `#F0E8D2`(领衬)。
- 随身: 木十字、皮包(装草药与一小瓶青柠糖浆)、一本手抄祈祷书。
- 出图提示词: 半写实厚涂, 航海时代传教士修士袍束麻绳, 胸前木十字, 背旧皮包拿草药, 温和, 港口渔光。

## 5. 行会代表(商人公会) —— 投资/独占
- 游戏里: 投资港口的占有率、谈"独占某种货"、发放商会任务。
- 剪影: **铜链金章(公会徽) + 双排扣长袍 + 双手交叠在账册上**; 蓄整齐山羊胡。
- 服装: 深靛 `#20344A` 或铁灰呢长袍, 白亚麻领巾打结; 头戴窄边高帽(商人帽)。
- 主色: 深靛/赤金 `#C9A227`(链章)/旧纸。
- 随身: 公会金章(圆盘指南针纹, 呼应商会徽的变体)、鹅毛笔、蜡印戒。
- 出图提示词: 半写实厚涂, 商人行会代表蓄山羊胡, 双排扣深靛长袍胸前金链公会章, 白领巾窄边高帽,
  手交叠于账册, 精明而体面。

## 6. 海盗头目(可遇不可交) —— 遭遇战/黑旗
- 游戏里: 海上遭遇的"敌对化身"; 打赢拿声望, 打输被劫。
- 剪影: **破旗披风 + 独臂铁钩或弯刀 + 宽沿旧帽压住半脸**; 站姿嚣张、重心前倾。
- 服装: 帆麻与皮革拼的旧外套(猩红 `#8E3A2F` 残旗披肩), 铁灰 `#3A4148` 弯刀; 脸上旧疤。
- 主色: 猩红/墨线/铁灰 + 一点赤金(耳环)。
- 随身: 弯刀或火绳枪、腰间劫来的各色钱袋(尺寸不一, 暗示"刚劫过")。
- 出图提示词: 半写实厚涂, 大航海时代海盗头目, 破旗披风与皮革拼外套, 弯刀与火器, 宽沿旧帽压眼,
  猩红残旗元素, 阴天怒海, 全身立绘(可作敌方立绘)。

## 7. 独眼老水手 —— 向导/秘闻
- 游戏里: 卖"某条航线的危险与顺风"情报、偶尔接到隐藏小支线。
- 剪影: **独眼罩 + 蜷在码头酒桶边 + 一根长烟斗**; 瘦而骨架大, 讲故事时指天划地。
- 服装: 一层又一层旧呢(深靛/帆麻堆叠), 粗呢斗篷补丁; 膝上一卷旧海图。
- 主色: 深靛/帆麻/鞣革 `#7A4B2B`(眼罩带)。
- 随身: 长烟斗、独眼罩、用绳系着的老怀表(不走字, 当吉祥物)。
- 出图提示词: 半写实厚涂, 独眼老水手蜷坐码头, 堆叠旧呢与补丁斗篷, 长烟斗, 膝上旧海图, 讲故事神态,
  傍晚渔火。

## 8. 占星家/观星人 —— 大事件预报
- 游戏里: 用模糊"星象签语"提示即将到来的大事件(telegraph 入口之一)。
- 剪影: **拖地星象袍 + 尖帽或环形髻 + 手举一架黄铜小象限仪对天**; 走路带起一地星图。
- 服装: 靛蓝染 `#2E4B8F` 袍绣旧纸色星轨; 或沙漠吉普赛风的头巾披巾(地区变体)。
- 主色: 靛蓝染/旧纸/黄铜 `#C19A3B`(象限仪)。
- 随身: 小象限仪/星盘(与船员用的成对, 暗示同一知识体系)、一卷星图、装"签语"的小布袋。
- 出图提示词: 半写实厚涂, 观星占星者拖地星象袍对天举黄铜象限仪, 袍面旧纸色星轨刺绣, 星图卷与签袋,
  入夜天文台/巷口, 清冷星光。

## 9. 黑市掮客 —— 走私/禁忌货
- 游戏里: 卖"违禁/抢手"货、高价情报; 议价反转大, 信誉低。
- 剪影: **长披风内衬翻起(塞满小包) + 半掩面的高领 + 走路无影**; 身形细瘦、耸肩。
- 服装: 墨灰/深靛 `#20344A` 长风衣式外套(内袋无数), 兜帽可用; 手拢在袖里。
- 主色: 墨线/深靛/赤金(只露一环金链表示"有钱但脏")。
- 随身: 袖内小秤、一小包违禁货(样品)、蜡封信(接头暗号)。
- 出图提示词: 半写实厚涂, 码头暗巷黑市掮客, 内袋无数的大披风拢手半掩面, 袖中藏小秤, 背光一盏灯,
  警觉狡黠, 全身半身皆可。

## 10. 码头少年 —— 廉价情报/跑腿
- 游戏里: 给很少金币就替你跑腿/带口信, 大事件来临前"街头都知道"的热度来源。
- 剪影: **赤脚 + 破短衫 + 别着一根太长的竹竿当桅杆玩**; 机灵、泥腿。
- 服装: 帆麻 `#E7D9B6` 破短衫(大一号), 挽到肘; 短裤赤脚; 头戴大人帽(捡的)。
- 主色: 帆麻/陶土 `#B0522F`(补丁)/深靛(帽子)。
- 随身: 竹竿、揣怀里的半个硬饼干、挂绳上几枚零钱(他的全部)。
- 出图提示词: 半写实厚涂, 码头赤脚少年穿大一号破短衫戴大人旧帽, 扛长竹竿当船玩, 神情机灵,
  渔港日光, 全身。

## 11. 贵族总督 —— 独占/许可证
- 游戏里: 发放"独占贸易/特许状"; 高阶港的重要人物。
- 剪影: **白亚麻大翻领 + 金银绶带 + 拄手杖**, 蓄长须、端坐或站在阳台俯看码头。
- 服装: 深靛/墨线长袍外套 + 帆白 `#F0E8D2` 大翻领, 赤金 `#C9A227` 绶带与印章链。
- 主色: 深靛/帆白/赤金。
- 随身: 镶银手杖、蜡印戒指(盖"特许状")、一只宠物猴或信鸽(地区变体)。
- 出图提示词: 半写实厚涂, 殖民地贵族总督白亚麻大翻领深靛长袍, 赤金绶带与印章戒, 拄镶银手杖,
  俯视港口的端坐姿态, 室内暖光。

## 附录 · 地区服饰速查(给港角换装)
把上面任一"母版"换地区时, 直接改**外衣与头饰**即可:
- **北欧/英格兰**: 厚呢 + 皮靴 + 羊毛大氅; 色调偏深靛/铁灰。
- **伊比利亚/地中海**: 紧身上衣 + 宽口裤 + 宽檐帽/披风; 暖赭与靛蓝。
- **西非/圣多美**: 轻棉麻 + 蜡染纹 + 珊瑚/黄铜珠饰; 帆白与陶土。
- **阿拉伯/东非**: 长袍(thobe) + 缠头 + 腰刀; 旧纸与靛蓝白。
- **印度/锡兰**: 纱丽/dhoti + 缠头巾 + 金线; 靛蓝染与赤金。
- **东南亚**: 纱笼(sarong) + 织金腰带; 青柠绿与陶土。
- **大明/日本**: 长衫/和服(当地纹理); 靛蓝染为主。
- **新大陆**: 欧洲式皮甲/绒布 + 原住民棉织点缀; 陶土与青柠。
