# 《海商：世界商路》玩法与数值设计文档

> 项目代号 **SEA** —— 用 Unity3D 复刻《大航海时代 4》**玩法内核**的航海贸易模拟。
> 本作只复刻"玩法神似"：世界地图 + 港口物产与百姓需求构成贸易基础 + 时间演进 + 大事件扰动。
> 港口、商品、剧情均为基于真实地理/历史物产的**原创设计**，不做原版素材与逐城数据的复制。
>
> 配套数据（`Assets/Resources/SeaData/*.json`）与本文档一致，可直接被 `Assets/Scripts/Sea.Core` 加载。

---

## 0. 一句话玩法

> 你在 16 世纪的真实世界里驾驶商船：**在物产便宜的港口买进，运到当地百姓急需的港口卖出**。
> 港口会随着季节、随机行情的漂移和时不时发生的大事件改变买价与卖价 ——
> 会看行情、赌事件、跑对航线的商人赚得多，闷头乱跑的破产。

## 2. 玩法循环与系统关系图

```
                 ┌───────────────────────────────┐
                 │         世界时钟 Calendar       │
                 │   月/日推进, 季节, 年份          │
                 └───────┬───────────────────────┘
                         │ 每个港口每个商品逐日更新
   ┌────────────┐        v        ┌──────────────┐
   │  港口 Port  │  ──►  港口市场   ◄──  大事件 Event │
   │ 特产/需求   │      MarketCell  │ 战争·饥荒·节日… │
   │ 城市规模    │   (价格倍率 r、   │ 影响需求/供给    │
   │ 坐标/气候   │    库存 stock、   └──────┬───────┘
   └────────────┘    目标价 eq)             │
        ▲                                 v
        │ 航行耗时/到达                   酒馆传闻(情报)
        │                               ┌──────────────┐
   ┌────┴────┐   买低卖高 + 议价     ┌───┴──────────────┐
   │ 玩家船队 │ ────────────────────► │  交易声望/投资    │
   │ 货舱容量 │ ◄────────────────────  │  解锁特产·新航线  │
   └─────────┘       差价利润         └─────────────────┘
```

**核心闭环**：买货 → 远航 → 找高价卖 → 赚差价 → 提升交易声望 → 解锁更好情报与特产 → 买更稀有的货……（海战、剧情、霸者之证等全部作为后续扩展挂在此闭环上，见 §9。）

## 3. 世界地图与 8 大航区

世界地图采用**真实地理的经纬网格**（等距圆柱投影放置港口标记），而非瓦片拼图——这样：
- 港口用 `(lat, lon)` 定位，地图绘制、航行时间、气候带判断全部由数据推导；
- 换美术底图只需替换贴图与缩放，不改逻辑；
- 将来可无缝接入真实海岸线/洋流数据。

### 3.1 航区划分（8 个）

以真实历史贸易圈划分，而非按原版海域名：

| 航区 id | 名称 | 推荐阶段 | 说明 |
|--------|------|---------|------|
| `northSea` | 北海·北欧 | 入门 | 波罗的海-北海，咸鱼/黄油/羊毛/琥珀产地 |
| `med` | 地中海·伊比利亚 | 入门 | 旧世界贸易心脏：葡萄酒/橄榄油/玻璃/东地中海转口 |
| `westAfrica` | 西非·大西洋 | 中级 | 黄金/象牙海岸 + 圣多美蔗糖 + 好望角中转 |
| `eastAfrica` | 东非·红海 | 中级 | 象牙/黄金/乳香/咖啡（也门摩卡），印度洋门户 |
| `india` | 印度·波斯湾 | 高级 | 胡椒/棉布/靛蓝/宝石/肉桂（锡兰）|
| `seAsia` | 东南亚 | 高级 | 香料群岛：丁香/肉豆蔻/锡/檀香；白银热土 |
| `eastAsia` | 东亚 | 终极 | 丝绸/瓷器/茶叶/人参，白银大买家 |
| `newWorld` | 新大陆·美洲与加勒比 | 中级 | 糖/烟草/可可/毛皮 + 白银与黄金（宝藏航线）|

> 航区主要服务三个目的：① 关卡感与成就感（越远越值钱）；② 经济上形成"产地—需求地"的地理价格差；③ 大事件的作用域（`§7`）。数据上每个港都有独立经纬与气候，航区只是聚合标签，可随时重划。

### 3.2 航行与时间

- 港口间航行耗时 = 由球面大圆距离 / 日航速推算（洋流/季风/逆风作为后续加成项）。
- 航行中世界时钟继续走 → "等你到货时行情已经变了"是核心紧张感来源。
- 地图上以航区颜色 + 港口标记呈现；点击任一港口查看该港买卖行情。

## 6. 时间要素：需求的"活"

> 这是"百姓的需求会随时间变"的落地：三层时间信号叠加在一个倍率上。

### 6.1 世界时钟
- 游戏内 **1 天** = 一次经济 tick；月/年由累计天数推导（起始 **1550 年 1 月 1 日**）。
- 采用**游戏历：1 年 = 360 天 = 12 个月 × 每月 30 天**（非公历），纯粹为了让"天→月→季节"的换算可整除、可预测。数值设计全部按此历进行。
- 航行、等待、事件、补货全部按天数计算 → 时间就是成本，"行情等不起"。

### 6.2 第一层：季节（气候带 × 商品需求类型）
- 每个港口按其气候带给不同商品的季节倍率 `seasonMul(m, port.climate, good)`：
  - **冷/温带（北半球）**：11–2 月，葡萄酒/烈饮/毛皮/咖啡/茶/糖/珍品的需求上调（室内保暖、节庆豪饮）；5–8 月下调。必需品(小麦/咸鱼)常年 1.0。
  - **热带**：基本 1.0（无冬夏），但热带货(糖/咖啡/可可)有自己的采收窗口——采收期产地供给大增 → 产地价更低（适合进货）。
- 季节只作用于**需求方/价格拉力**，不改变产量；产量波动由"大事件"或"随机漂移"承担。

### 6.3 第二层：缓慢漂移（行情偶然变好/变坏）
- 每个 `(港口, 商品)` 的**均衡价倍率 eq** 每天做微小均值回复的随机游走（σ≈0.006，向"基准 eq"回拉）。
- 效果：偶尔某个港的咸鱼行情会连好一周、某样东西突然滞销——制造"货比三家、赌一赌"的乐趣。纯数据可关。

### 6.4 第三层：你的行为也在改变行情
- **买空特产** → 本地价格上涨（你也买不起更多）；**倾销某货** → 本地价格被你砸低。
- 商船带来的货太多会"砸价"，太少则"涨价"——完美复刻 UW4 里"一次吃进太多会坏行情"的手感。

### 6.5 交易声望（时间维度的反馈）
- 每笔"卖往本地百姓正缺的货"按利润积累声望；声望高 → 解锁该港的完整行情情报、议价权、并最终"独占港/同盟港"地位。作为后续系统，字段已预留。

## 7. 大事件：扰动供给与需求

### 7.1 事件模型
每个事件是数据里的一条规则，四要素：
1. **范围** `scope`：作用于 `全球 / 航区 / 港口 / 某商品 / 某需求类型`
2. **效果** `effect`：需求上升/下降（乘在 eq 上）、供给上升/下降（乘在产地 eq 上）、封锁某港（禁止交易 N 天）
3. **时机** `schedule`：一次性(`DayOffset`)/ 每年循环(`Yearly`)/ 周期(`PeriodYears`)
4. **情报** `telegraph`：是否上"酒馆传闻"让玩家有机会提前押注

> 规则引擎把当前所有命中该 (港口,商品) 的事件倍率相乘 → 得到"当天的 eq 有效值"，再让价格倍率 `r` 以每日惯性逼近它。所以事件影响是**渐变的、可被玩家捕捉到入场时机**的。

## 8. 市场价格数值模型（SimEngine 规则本体）

> 设计目标：**少而直观的参数 + 行为自洽**，全部集中在 `MarketTuning.json`，方便平衡。

### 8.1 关键量
- **基准价 `base`**：每商品全球不变（§5 表）。
- **目标价倍率 `eq`**：每 (港口, 商品) 的"长期均衡价 / base"。由角色决定：
  - 本港**特产**：`eq = 0.60`（过剩 → 贱卖，好进货）
  - 本地**百姓需求**（必需）：`eq = 1.40`（缺货 → 贵，好出货）
  - 本地**百姓需求**（嗜好/珍品）：`eq = 1.70`（愿为心头好出高价）
  - 特产 **同时**也是本地常需：`eq = 0.85`（自产自销微利）
  - 与本港无关：`eq = 0.98`（什么都有一点，价格贴全球基准）
- **现价倍率 `r`**：真正挂牌的倍率。`买价 = base × r`；`卖价 = base × r × 0.94`（商栈抽成）。

### 8.2 每日更新（每个港口 × 每个商品）
1. `eqEff = eq × 季节倍率 × Σ事件倍率 × (1+噪声漂移)`
2. `r += (eqEff − r) × 0.10`（价格以 10%/日的惰性逼近目标，事件/季节的影响被"拖"成趋势而不是瞬间跳变）
3. 钳制 `r ∈ [0.25, 3.0]`
4. 库存回补（决定能买多少）：特产大额快速回补；无关货小额极慢回补（象征别处商人零星到货）。

### 8.3 玩家交易后的反馈
- 买入 1 单位：`r += 0.006`（你抽空了供给，越买越贵）
- 卖出 1 单位：`r -= 0.008`（你灌满了市场，倾销自砸价）
- 于是：单笔大额买入有限制、重复在同一港倾销利润递减 → 必须"换港/换货/等行情"。

### 8.4 这一模型为什么"像大航海4"
- 特产永远在产地最便宜（前提你愿意扛着风险跑远洋）；
- 珍品/嗜好品在有需要的富庶港能卖出超高溢价，但**一次砸太多就贱**；
- 季节、漂移、大事件让**"现在卖"还是"憋到下个港"**成为天天要做的选择题；
- 玩家能影响单个市场价格，形成"传货=做市"的沉浸感。

## 9. 技术架构与里程碑

### 9.1 分层的理由
- `Sea.Core`（纯 C#，**零 UnityEngine 依赖**）：经济模型 + 事件规则 + 时间。可被 **dotnet 控制台直接驱动做平衡测试与回归**（见 `dev/SimCheck`）。
- `Assets/Resources/SeaData/*.json`：所有内容数据（商品/港口/航区/事件/调参），换皮即换内容。
- Unity 运行时仅做**展示与交互**：世界时钟、地图标记、点击查行情、买卖面板。
- 好处：数值可以**在不开 Unity 的情况下**用脚本仿真、压测、自动化回归；美术/内容与逻辑解耦。

### 9.2 当前骨架（本次交付）
- 可运行验证：`dev/SimCheck` 加载全部数据跑 3 年，验证不炸、价格钳制、事件生效、商人 Bot 能赚钱。
- Unity：编辑器菜单 `Tools/SEA/校验数据` 复跑校验；`Tools/SEA/搭建主场景` 生成带港口标记的世界地图调试场景，可播放、点选港口看行情。

### 9.3 里程碑（Roadmap）
1. **M0 经济沙盒（本次）**：世界时钟 + 市场 + 事件引擎 + 数据校验。
2. **M1 船队与买卖 UI**：货舱、资金、议价（喊价三连）、买卖面板、行情情报（付费预览价格色标）。
3. **M2 航行**：船速/风、续航补给、随机遭遇、海战胜负结算；贸易声望/独占港/投资。
4. **M3 内容扩展**：更多商品/港、随机海盗与历史事件池、"霸者之证"式的区域制霸目标、多个主角商会差异化。
