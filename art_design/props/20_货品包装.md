# 货品包装 · 美术设定稿

> 设计**货物在仓/交易/在船上的"实物形态"**——游戏里点一单货, 看到的是它的成包样子。
> 对应 `Assets/Resources/SeaData/Goods.json` 的商品(每组取代表色与形态, 不必每件单独建模)。
> 旧化底色统一: 麻布起毛、标签泛黄、木箱钉锈。

---

## 大宗粮·食
### 小麦/大米/椰枣等
- 形态: **粗麻袋**(帆麻 `#E7D9B6`), 袋口用麻绳扎紧后翻卷; 地上叠放时互相倚靠, 袋面写炭字(存量/港名)。
- 主色: 帆麻 / 陶土 `#B0522F`(麻字) / 少量燕麦金点缀。
- 出图提示词: 码头仓库成堆小麦麻袋, 帆麻粗织袋口翻卷系绳, 炭笔字, 顶光, 厚涂写实。

## 布匹
### 呢绒/棉布/丝绸
- 形态: 呢绒=厚卷筒(深靛 `#20344A`)外裹麻布; 棉布=方捆(印花粗布, 靛蓝染 `#2E4B8F` 纹); 丝绸=**轻薄缎匹**卷芯(金线 `赤金 #C9A227` 扎), 外层蜡纸。
- 主色: 深靛 / 靛蓝染 / 赤金(扎带)。
- 出图提示词: 三种成卷布匹并置(厚呢卷、棉布方捆、丝缎蜡纸卷), 质感对比明显, 厚涂。

### 丝绸特写(旗舰货)
- 形态: 缎面折光(旧纸 `#D9C08A`→象牙 `#E8DFC2` 高光), 竹芯卷, 麻布系带。
- 出图提示词: 一匹半展开的旧式丝缎卷, 缎面折光与竹卷芯, 麻布带, 富丽但克制, 厚涂。

## 远东珍货
### 瓷器(泉州青花/景德镇)
- 形态: 一只青花大罐或成叠盘碗, **稻草绳网**整器捆扎(网纹清楚), 侧立一只木箱(内衬麻布)。
- 主色: 青花钴蓝(以靛蓝染 `#2E4B8F` 显其青)→ 实际用 `#2A4A9C` 偏钴的青 + 帆白胎 + 稻草 `旧纸 #D9C08A`。
- 出图提示词: 青花瓷罐以稻草绳网整器捆扎, 旁放麻布衬木箱, 俯视, 瓷器反光, 厚涂。

### 茶叶
- 形态: **竹茶篓**(编竹筐内衬油纸, 盖荷叶)为主; 高级茶用**小锡罐**(铁灰 `#3A4148`, 印花茶褐 `#6B4A2F`)。
- 主色: 竹青(以青柠 `#7C8E2E` 提) / 油纸黄(旧纸) / 茶褐。
- 出图提示词: 竹编茶篓开口露出油纸内衬与干茶叶, 旁放印花锡罐, 港口晒场, 厚涂。

## 香料
### 胡椒/丁香/肉豆蔻/肉桂
- 形态: 粗帆布**小袋**(袋口缝死) + 大号**陶罐**(陶土 `#B0522F`)存上等品; 袋面压暗色香料渍。
- 主色: 帆麻 / 陶土 / 黑褐 `#6B4423`(香料色, 用"黑胡椒"特有暗褐)。
- 出图提示词: 胡椒麻袋与陶罐并置, 袋口缝线, 陶罐内深褐胡椒粒, 香料气氛围, 厚涂。

### 檀香/乳香(香货)
- 形态: 檀香=成束短木(浅褐)麻布束; 乳香=树脂碎块装小皮袋(鞣革 `#7A4B2B`), 配一只小铜香炉(呼应萨利玛的银香盒)。
- 主色: 浅柚木 / 鞣革 / 铜 `#C19A3B`。
- 出图提示词: 檀香木束与盛乳香树脂的小皮袋及铜香炉, 轻烟一缕, 厚涂。

## 糖·嗜好
### 蔗糖
- 形态: 蔗糖压成**锥形糖塔**, 外包深蓝粗布(靛蓝染), 或装小木桶(柚木 `#8A5A2B`)。
- 主色: 帆白(糖体高光) / 靛蓝染(包布) / 柚木。
- 出图提示词: 锥形糖塔外裹靛蓝粗布, 旁有糖木桶, 仓库暗角一束光打亮糖体, 厚涂。

## 贵金属·宝石
### 银锭/金条/铸币
- 形态: 银锭成排码在**带锁木箱**(橡褐 `#6B4423`, 铁带加固); 金条用**皮袋**单装; 铸币散落桌面几枚。
- 主色: 银灰/赤金 `#C9A227` / 橡褐 / 铁灰。
- 出图提示词: 开盖木箱内成排银锭, 皮袋半敞露出金条, 桌面数枚旧币, 烛光, 厚涂。

### 珍珠/宝石
- 形态: 珍珠=丝质小袋(象牙 `#E8DFC2`)开口洒出几颗; 宝石(祖母绿/蓝宝石)=**锦盒**(靛蓝染内衬绒)分层。
- 主色: 象牙 / 靛蓝染(内衬) / 青柠绿(祖母绿点缀)。
- 出图提示词: 丝袋珍珠与绒里锦盒宝石同框, 小物大光, 深色底衬, 厚涂特写。

### 象牙(整根)
- 形态: 一对原牙以麻布束缠, 靠舱壁斜放, 顶端旧蜡封; 是"分量型"奢侈品(一人难搬)。
- 主色: 象牙 / 鞣革(束带) / 旧纸(蜡封)。
- 出图提示词: 一对麻布束缠的旧象牙斜靠船舱板, 舱窗光, 质感厚重, 厚涂。

## 染料·皮
### 靛蓝(饼) / 皮革(张)
- 形态: 靛蓝压成**蓝饼**(深蓝近黑), 以干叶/粗纸分层入篓; 皮革成**捆(双层对折)**以皮绳绑。
- 主色: 靛蓝染深块 / 鞣革 / 帆麻。
- 出图提示词: 靛蓝饼堆叠于叶垫竹篓, 旁两捆对折皮革皮绳绑, 染坊暗光, 厚涂。

## 附 · 打包通用规范(画师统一用)
1. **每类货一个"标准件"**: 麻袋/箱/桶/捆, 尺寸约 60cm 见方的"一人件"级(除了象牙/瓷大罐这类大件)。
2. 都会有一块 **货签**: 旧纸小牌挂绳/炭笔字, 标商品 id 短名(玩家能从小图认出"这是茶还是胡椒")。
3. UI 图标 = 该标准件正面 128px 剪影; 高价值货图标要一眼比普通货"体面"(镶边/缎带/锁具)。
