## 0. 一句话玩法循环(加入船以后)

```
港内: 买船 → 造船厂升级/买僚舰 → 招募水手+舰长/军官
     → 装货物 + 买补给(食粮/茶叶/维生素) → 出海(逐日推进, 消耗补给)
海上: 换日 → 各港需求/事件在演变; 可能遭遇海盗(迎战/避战/破财)
到港: 卖货 → 议价 → 补给休整/治坏血病 → 结算月薪 → 投资提升港占有 → 再出发
```

船把原来的"点对点瞬时交易"变成**有时间成本与远航约束的贸易**, 大事件/需求变化因此真正"吃得着"。

## 1. 船的核心属性(词条释义, 与需求逐条对应)

| 你点名的项 | 设计字段 | 含义 |
|---|---|---|
| **型号 / 世代** | `model`/`tier` | 见 §3; 世代(1 近岸 → 4 大洋)决定能去多远的洋面与造价 |
| **仓位** | `slots`(格) | 同时能装几种货物/补给(分类格)。高仓位=能铺多样化短线, 低仓位=只能押注单一航线 |
| **载货量** | `capacity`(点) | 与 `Goods.json` 的 `weight` 同尺度: 一件 `weight:2` 的货占 2 点。船舱重+补给重量都从这里扣 |
| **价格** | `price`(金) | 造船/购买价; 另设 `refit` 改造费用见 §4 |
| **水手数量** | `crewMin`/`crewMax` | 最低航行人手(低于则降速)与定员(上限)。见 §5 招募与开销 |
| **火力** | `guns`(炮门)/`fire` | 火炮数与综合火力指数(海战攻击力) |
| **抵抗海盗能力** | `armor`/`crewCombat` | 船体护甲(硬扛) + 水手战力(人挡); 与船速一起参与 §7 遭遇结算 |
| **续航** | 无固定值 | 船本身不写死"可航几天"; 由 **船员×补给消耗** 推导, 见 §2 |
| 航速 | `speed`(节) | 决定两地之间耗时(海里/节 = 天数), 见 §2 末 |
| 其他 | `type`(商/战/快/综合) · `areaUnlock`(可造/可买的航区) · `year`(约需年代) · `desc` | 让内容有升级成长曲线 |

> 一句话手感: **商船=大而软, 战船=硬而凶但装得少, 快船=快而脆**, 你的舰队就是在这三者里配比例。

## 2. 航海补给与"能在海上航行多久"

### 2.1 三种消耗补给(全部占用货舱, 会腐烂/占重)

| 补给 | 单位重量 | 进价(金/单位) | 每名水手·每日 | 作用 |
|---|---|---|---|---|
| **食粮**(含淡水/硬饼干/咸肉) | 0.02 | 1 | 1.0 单位 | 生命线。断了立刻出事(见 2.3) |
| **茶叶** | 0.01 | 6 | 0.1 单位 | 远航士气/防单调。断了士气崩 |
| **维生素**(青柠/浓缩柑橘) | 0.005 | 12 | 0.05 单位 | 防坏血病。断了潜伏期后船员病倒 |

设计上故意**把"茶叶"和"维生素"设为两回事**: 茶管"心情"(士气), 柠檬管"身体"(坏血病),
让玩家在"多带货赚钱"与"多带补给保命"之间做真实取舍。茶叶同时仍是 `Goods.json` 里的贸易品,
你要么把它当货物卖, 要么留给自己船上喝——同一个商品两种用途。

### 2.2 续航公式

```
按当前船员数 C 与库存, "硬续航"(某补给先见底的天数):
  dayRations = 食粮库存 / (C × 1.00)
  dayTea     = 茶库存    / (C × 0.10)
  dayVitamin = 维生素库  / (C × 0.05)
  最长航行天数 ≈ min(dayRations, dayTea, dayVitamin)   (向下取整)
```

**试算示例(可见比例合理):**
- 卡拉维尔商船(定员 80), 载重 150 点, 装 45 日给养约需:
  食粮 80×45×1.0=3600 单位 ×0.02 = **72 点**; 茶 360 单位 ×0.01≈**4 点**; 维生素 180×0.005≈**1 点**;
  合计约 **77 点 = 载重一半多一点**——留一半载货, 兼顾远航与赚钱。
- 燕隼近海船(定员 18), 载重 30 点: 30 日给养约 11 点, 短途绰绰有余。

### 2.3 缺什么会怎样(把"时间"变成压力)

| 缺的补给 | 潜伏期 | 之后的效果 |
|---|---|---|
| 食粮 | 0 天(立即) | 每日士气 -15; 次日开始每天最多 20% 水手病亡/叛逃; 约 5 日不靠港 → 全灭 |
| 茶叶 | 第 3 天起 | 士气每天 -3; 士气 <40 航速 -10% 且"想靠港"事件概率上升; <20 每日可能哗变减员 |
| 维生素 | 第 15 天起(远航缺维C潜伏) | 每 3 日 1 名水手患坏血病; 每 1 病号拖累航速 2%; 病号>定员 20% → 船显著减速, 强烈逼你进港 |

**靠港治疗**: 花金币让船医/修女院治坏血病、补满给养、士气回 80。港内"自动补 45 日给养"一键按钮。

### 2.4 船速与两地耗时(挂接现有经纬度)

```
两地距离(海里) ≈ 球面/网格距离 × 单位换算(具体在 M1 移动实现时定)
航行天数 = ceil( 距离(海里) / (speed 节 × 24) )
```
海上每天照常走 `SimEngine.AdvanceDays(1)`, 所以**市场、大事件、季节在你航行途中持续演化**——
这也是把需求"随时间变化"真正玩起来的支点。

## 4. 造船、改造与折价

- 每个港口有造船厂等级(并入"投资"概念, M3), 高级船只在指定航区才买得到(见上表"入手")。
- **改造(refit)**: 每船可用金币改造, 消耗造船厂产能:
  | 项目 | 效果 | 参考花费(占船价%) |
  |---|---|---|
  | 加装货舱 | 载重 +10~25% | 15–30% |
  | 加炮甲板 | 火力 +20~35% | 20–40% |
  | 包铜/包铁 | 护甲 +15~25% | 15–25% |
  | 换桅/船型减员 | 航速 +1~1.5 节 | 15–25% |
- 船可折旧卖出(约 6 成); 保留上限: 船坞容量随"舰长声望/商会等级"提升。

## 5. 舰队编成(主船 + 护卫 + 最终成队)

- **编成上限**: 1 旗舰 + 4 僚舰 = **最多 5 艘**(参照原作规模, 规则原创)。
- 旗舰决定:
  - 你操控的航行速度/补给结算以旗舰为主, 僚舰跟随; 各自独立占船员、各自算护甲;
  - **交易只在旗舰**进行(僚舰满载随行, 卖了旗舰的货再去分装)。
- 僚舰**不是凑数**——作用不同:
  | 僚舰角色 | 为什么带 |
  |---|---|
  | 护卫战船 ×1–2 | 海盗结算时提供火力/护甲(§7); 没有护卫, 载着金货出远洋=送菜 |
  | 快船 ×1 | 前方探路/赶行情; 遇强敌时全队避战需要舰队最高速 |
  | 大商船 ×1 | 总载货量翻倍以上, 一次多吃一个港的存货(也吃行情) |
- 舰队合计: 总载重/总水手/总炮火/总护甲——出港前在"出航清单"上一目了然。
- **典型编成示例**:
  - 前期(≈15–30万): 旗舰卡拉维尔商船 + 卡拉维尔战船 → 沿海两港短线稳妥跑。
  - 中期(≈50–150万): 旗舰南海大帆船(福船型) + 大型克拉克战 + 飞笛货 → 印度洋↔中国沿海跑香料/瓷器, 一条船吃货, 一条船护航。
  - 后期(≥300万): 旗舰东印度大商船 + 皇家盖伦战×2 + 龙渊·宝船级 → 环球黄金航线, 一个来回吃满 4 个航区。

## 6. 水手: 招募、月薪、士气、坏血病(人也是成本)

- 在港招募: 每水手招募金 = 依港劳动力紧张度波动(参考数据 `crewMarketFactor`), 旗舰+僚舰合计上限以内。
- **月薪**: 在港(每进港结算一次, 不按月等)支付: 普通水手约 8 金/人; 军官见 §8 NPC。(已定: 按进港结算, 见 §10.1)
- 士气影响(0–100): 缺茶/缺食粮/被海盗洗劫 → 掉; 靠港补给、发酒、打胜仗、好伙食 → 涨。
  士气高 → 航速与海战 +%; 士气低 → 减速、哗变、甚至拖你靠港。
- 坏血病/伤病: 靠船医 NPC(§8)减少损耗、治疗更快。

## 7. 海盗与迎战(初版, 数据驱动)

- **危险度**: 每个航区有 `danger 0~1`(写入数据), 大事件可临时抬升(复用 Events 机制, 如"巴巴里海盗季")。
- 每日航行: 遭遇概率 = `danger × 航线热络度(近期成交额) × 船上货值系数`——**载着金贵货走险路风险自担**。
- 遭遇后三选一:
  1. **迎战**: 战力判定(见下), 胜 → 声望+、可夺对方少量货; 负 → 被洗劫(掉货/掉士气/可能被夺船)。
  2. **避战**: 需要 舰队最高速 > 海盗速 × 1.15 才稳; 失败则仍被追上来开打且劣势。
  3. **破财消灾**: 付 船货总值 5~15%(可谈判, 会计 NPC 有加成), 保平安。
- **迎战结算(确定性, 非手操)** —— 已定: M2 一律自动查表, 手操推迟到 M3(见 §10.2), 判定值:
  ```
  attack  = 全队火力 × (1 + 旗舰水手战力系数) × 士气/100
  defense = 全队护甲 × (1 + 水手总数/舰队定员比) × (1 + 训练/经验)
  胜率(迎战) 由 attack/敌attack 、 defense/敌炮伤 两张表查表得(做成查表, 便于调)
  ```
- 海战结果仍以**经济后果**为主(掉货、掉价、多付月薪、士气), 不做完整海战小游戏(M3 可选)。

## 10. Roadmap 落点与后续

- **M1 船队与买卖 UI**: 先把 `Ships/Crews/FleetTuning` 装载进引擎, 出"港口→造船厂/酒馆/市场"界面;
  舱容与议价三连(接现有 Bid/Ask)。
- **M2 航行**: 移动与逐日消耗、续航 UI、遭遇与迎战结算(§2/§7); 时间压力让市场演化有意义。
- **M3**: 剧情大事件里 NPC 出场/离职、独占船(宝船/大安宅)、海盗势力声望、完整海战可选。

### 已定取舍(2026-09 定稿, 实现按此走; 若要改回请再说明)
1. **水手月薪 = 按进港结算**(每次靠港统一付一次月薪, 不逐日/逐月扣)。海上只耗补给不扣工资 → 鼓励玩家"出港憋长线、进港结大账", 运营手感更宽松, 记账也简单。
2. **海盗遭遇 M2 一律自动结算**(§7 查表判定), 战斗脚本留 `BattleAction` 接口, **手操微操推迟到 M3** 做可选内容。先保"贸易 + 风险成本"主线不被战斗系统拖住。
3. **茶叶 = 双用途补给**: 可当贸易品卖, 也可装船当远航补给(提士气)。设计成"同样的茶, 卖给别人赚钱 / 留给水手换平安"的二选一。
4. **数值一律先占位**: `Ships/Crews/FleetTuning` 里的价格/火力/补给/危险度都是初版建议值, 等 M1 实机试玩一轮后再回填校准。SimCheck 只查结构与量纲, 不断言平衡好坏。
